# 🎬 Motion Diagram Design Skill (V3.0 Universal Edition)

시스템 아키텍처, 엔터프라이즈 비즈니스 프로세스, 소프트웨어 파이프라인, 고객 여정 맵 등 모든 종류의 업무 흐름(Workflow)을 **"살아 숨쉬며 스스로 움직이고 단계별로 해설하는 인터랙티브 모션 그래픽 HTML 아티팩트"**로 자동 제작하는 전문 범용 디자인 엔지니어링 스킬입니다.

---

## 📌 1. 언제 이 스킬을 사용하는가 (When to Use)

- 복잡한 시스템 구성도나 업무 프로세스를 단순 정적 그림이 아닌 **"자가 시연(Self-explaining Demo), 자동 순환 재생, 실시간 내레이션"**으로 전달해야 할 때
- 청중의 이해 속도에 맞추어 **재생 속도 조절(⚡ 0.5x, 1.0x, 1.5x, 2.0x)** 및 **환경별 라이트/다크 모드(`🌙 / ☀️`)**를 필수로 지원해야 할 때
- 프레젠테이션, 고객 온보딩, 품질 관리 보고, 아키텍처 감사 등 목적에 맞는 **10대 인포그래픽 디자인 테마(스윔레인, 교차 핀 타임라인, 셰브론, 로드맵, 허브 등)**를 선택/전환해야 할 때
- Windows 로컬 환경에서 단 한 번의 클릭으로 Google Chrome에서 전체 화면으로 실행되는 **독립형 배치 런처(`.bat`)**를 함께 납품해야 할 때

## 🛠️ 3. 범용 CLI 생성기 사용법 (Universal CLI Tool)

스킬 패키지에 내장된 Python CLI (`scripts/generate_motion_diagram.py`)를 사용하여 JSON 데이터로부터 즉시 다이어그램을 생성할 수 있습니다:

```bash
# 1. 수평 교차 핀 타임라인 생성
py scripts/generate_motion_diagram.py --theme timeline --input my_workflow.json --output timeline.html

# 2. 셰브론 화살표 파이프라인 생성
py scripts/generate_motion_diagram.py --theme chevron --input my_workflow.json --output chevron.html

# 3. 타이틀 및 서브타이틀 직접 오버라이드
py scripts/generate_motion_diagram.py --theme timeline --title "AI 배포 파이프라인" --subtitle "모델 학습부터 카나리 배포까지"
```

## ⚙️ 5. 전 테마 공통 필수 기능 표준 규격 (Universal Controls)

모든 아티팩트는 외부 서버나 네트워크 연결이 차단된 에어갭 환경에서도 100% 자립 동작할 수 있도록 단일 파일(Self-contained)로 제작하며, 아래의 필수 제어기를 공통 탑재합니다:

1. **상단 고정 헤더 (`position: sticky; top: 0; z-index: 1000;`)**:
   - 스크롤을 내려도 항상 최상단에 고정되어 언제든지 재생, 속도, 화면모드를 조작 가능
2. **4단계 속도 조절기 (Speed Control Mode)**:
   - 컨트롤 바에 `<button id="btnSpeed" class="btn btn-speed">⚡ 1.0x</button>` 배치
   - 클릭 시 순환: `⚡ 0.5x` (4.8초) ➔ `⚡ 1.0x` (2.8초) ➔ `⚡ 1.5x` (1.8초) ➔ `⚡ 2.0x` (1.1초)
   - 재생 중 속도 변경 시 즉시 타이머가 갱신되어 실시간 속도 반영
3. **반응형 라이트 / 다크 모드 (Light / Dark Switcher)**:
   - 컨트롤 바에 `<button id="btnTheme" class="btn btn-icon">🌙</button>` 배치
   - 토글 시 페이지 배경, 스테이지, 카드, SVG 내부의 모든 텍스트/도형/선이 고대비 보색(Complementary Color)으로 실시간 반전
4. **재생 / 내비게이션 엔진**:
   - `▷ 재생 / ❚❚ 일시정지` (단축키 `Space`)
   - `<` / `>` 수동 스텝 이동, `↺` 초기화 (단축키 `R`)
5. **상태 설명 드로어 (Detail Inspector Drawer)**:
   - 하단 2:1 정보 드로어 (좌: 상세 해설 및 체크리스트 / 우: 실제 소스코드 경로, 참조 문서, 보안 규칙)

## 🛡️ 6. 엔지니어링 함정 및 필수 구현 수칙 (Critical Pitfalls)

1. **다크 모드 보색 & 텍스트 시인성 원칙 (Chalkboard Complementary Contrast)**:
   - 다크 모드 전환 시 스테이지 컨테이너가 칙칙한 회색으로 남지 않도록 딥 네이비/슬레이트(`#0D1424`)와 네온 테두리(`#38BDF8`)를 적용한다.
   - SVG 내부의 텍스트가 어두운 배경에 묻히지 않도록, 다크 모드에서는 반드시 **선명한 분필 화이트(`#F1F5F9`)**, **일렉트릭 시안(`#38BDF8`)**, **형광 코랄 레드(`#F87171`)**, **앰버 골드(`#FDE047`)**, **민트 그린(`#34D399`)** 등 고대비 보색을 적용한다.
2. **Windows 파일 경로 이스케이프 (`SyntaxError` 방지)**:
   - 자바스크립트 문자열 리터럴 내부에서 절대 `path: "D:\path\"` 처럼 끝에 백슬래시(`\`)를 두지 않는다. 반드시 정방향 슬래시 `path: "D:/path"`를 사용한다.
3. **분기 카드 겹침 방지 (No Negative Margins)**:
   - CSS Grid 컬럼 내부에 여러 분기 노드를 넣을 때 `margin-top: -64px` 같은 음수 마진을 쓰지 않는다. Flexbox 컬럼 컨테이너(`<div class="branch-column">`)를 둔다.
4. **반응형 SVG 동적 도킹 (No Hardcoded Pixels)**:
   - 화면 해상도나 창 크기 변경 시 화살표와 라벨이 빗나가거나 겹치지 않도록 `getBoundingClientRect()`를 이용해 카드의 중심/가장자리 좌표를 동적으로 계산한다.
5. **배치 파일 Windows 인코딩 수칙**:
   - 모든 `.bat` 파일은 반드시 **`CP949` 인코딩**과 **`CRLF(\r\n)` 줄바꿈**으로 생성하여 한글 깨짐 없이 실행되도록 한다.
