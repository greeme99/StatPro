핵심 설계 포인트:
실시간 전송 페이로드 / 구현 코드 copilot.py 

      

    


    

      

        
1. 프로토콜 단일화 (CopilotProvider)

        
HTTP 기반 ExaoneCopilotProvider와 로컬 CodexSdkCopilotProvider가 동일한 answer() → CopilotGuidance 시그니처를 구현하여 호출부에서 완벽히 교체 가능합니다.

      

      

        
2. 프롬프트 행동 억제 & JSON 강제

        
에이전트의 도구 실행·파일 수정을 프롬프트로 금지하고, answer, recommended_tool, menu_path, checklist, workflow_steps 단일 JSON 반환만 요구합니다.

      

      

        
3. Read-Only 샌드박스 & 1-Turn

        
codex.thread_start(sandbox=Sandbox.read_only)로 파일 쓰기를 OS/SDK 차원에서 차단하고, thread.run(prompt) 1회 실행 후 즉시 스레드를 닫아 무상태 API로 동작합니다.

      

      

        
4. 경계 검증 & Fail-Closed 전환

        
_decode_llm_guidance_payload()로 코드펜스를 제거하고 스키마를 검증합니다. 실패 시 미검증 응답을 노출하지 않고 즉시 수동 안내(manual_guidance)로 안전 전환합니다.
