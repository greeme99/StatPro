# 일반 결함 분석 불변 개정 증거

## 범위

- 별도 `DefectAnalysisSnapshot`이 일반 결함 분석의 입력, 개정, 데이터 원천 근거를 소유한다.
- 체크 시트를 연결하면 범주별 결함 수가 저장된 체크 시트 집계와 정확히 일치해야 한다.
- 체크 시트 ID, 저장 ETag, 문서 digest를 분석 revision에 고정해 이후 원천 변경과 구분한다.
- 범주별 결함 수, 검사 기회, 단위 손실, 심각도에서 DPMO, 추정 손실, 위험 점수를 계산한다.

## 해석 경계

- DPMO는 사용자가 정의한 검사 기회 수를 분모로 한 우선순위 지표다.
- DPMO만으로 시그마 수준, 공정 안정성 또는 공정능력을 주장하지 않는다.
- 추정 손실은 입력된 단위 손실의 계산값이며 회계 확정값이 아니다.
- 위험 점수는 `결함 수 × 심각도`의 정렬 지표이며 FMEA Action Priority 또는 RPN을 대체하지 않는다.

## 검증

- 대상 Python 테스트 37개, 전체 Python 테스트 254개 통과.
- 변경 Python 파일 Ruff 통과.
- 웹 테스트 6개 파일 85개 통과.
- 웹 프로덕션 빌드 통과.
- 결정적 SBOM 갱신 후 OSS 게이트 통과.
- `git diff --check` 통과.

## 남은 범위

- 품질 지표 revision 정책과 조직 경보 정책.
- 일반 결함 분석을 DMAIC 관리 인계의 반응 계획과 연결하는 명시적 Evidence Reference.
- 규제·고객 보고서 템플릿과 승인 정책.
