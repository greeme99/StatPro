# DMAIC 측정 계획 불변 문서 계약

## 범위와 근거

- **사용자 제공 화면 참조:** 데이터 수집 계획은 지표·기준값·목표값, 수집 방법과
  주기, 표본 설계, 측정 시스템·교정·MSA 필요성을 기록하는 업무 화면 후보다.
- **구현 판단:** 계획에서 참조한 분석 결과는 후속 검토 시 같은 실행을 식별할 수
  있어야 한다. 따라서 Run ID뿐 아니라 분석 유형·저장 ETag·입력 digest를 저장한다.
- 이 증분은 외부 화면·브랜드·구현을 재사용하지 않으며, 독립적인 로컬 API 계약만
  제공한다.

## 구현된 계약

- `DmaicMeasurementPlan`은 1차 지표, 기준/목표값, 데이터 원천·수집·표본 설계,
  측정 장비·교정·MSA 필요성과 분석 실행 근거를 불변 문서로 보관한다.
- 프로젝트에는 최신 전문을 복제하지 않고 문서 ID·개정·digest 참조만 둔다.
- 연결하는 분석 실행은 저장소가 소유한 형식을 한 번 파싱하여
  `run_id`, `analysis_type`, `run_etag`, `input_digest`를 계획 문서에 고정한다.
- API는 다음을 제공한다.

  - `POST /v1/dmaic-projects/{project_id}/measurement-plans`
  - `GET /v1/dmaic-projects/{project_id}/measurement-plans/{document_id}`

## 작업공간 연결

- `/home/dmaic/measure`는 프로젝트 선택 또는 생성, 측정 지표·수집·표본·측정 시스템
  입력, 로컬 분석 실행 근거 선택, 저장 결과의 문서 ID·개정·근거 수 확인을 단일 흐름으로
  제공한다.
- 화면은 `GET /v1/analysis-runs`에서 받은 실행 ID만 서버에 전달한다. 서버는 저장 시점에
  소유한 실행을 다시 읽어 식별값을 고정하므로, 브라우저가 분석 유형이나 digest를 작성하지
  않는다.
- 저장 뒤 SPC·DOE·FMEA 작업공간으로 연결하되, 결과를 복제하거나 외부 시스템 상태를
  성공으로 표시하지 않는다.

## 검증과 제한

- 도메인 테스트는 불변 개정 사슬, 프로젝트 전문 미중복, digest 역직렬화와 실행
  근거 식별값 보존을 검증한다.
- API 테스트는 실제 저장된 I-MR 실행을 계획에 연결하고 계획 조회 시 동일한 근거가
  반환되는지 검증한다.
- 실시간 계측기 연동, 교정 이력 검증, 연결 Run의 사후 재검증 및 Word/PDF 내보내기는
  아직 이 증분에 포함하지 않는다.
