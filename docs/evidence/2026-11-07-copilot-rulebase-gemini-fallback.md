# AI Copilot Rulebase 우선·Gemini 폴백 증거

## 검증된 동작

- 검토된 현장 규칙이 먼저 실행되며, 일치한 질문은 외부 모델로 전송하지 않는다.
- 수율 Y와 온도·압력·시간 등 X 인자 탐색은 DOE 작업공간과 5단계 절차로 안내한다.
- 설비 비가동 원인 규명은 DMAIC 작업공간과 정의–측정–분석–개선–관리 절차로 안내한다.
- 규칙이 없는 질문은 `STATPRO_COPILOT_LLM_ENABLED=true`와 `GEMINI_API_KEY`가 모두 있을 때만 Gemini 2.5 Flash로 전달한다.
- 모델 응답은 추천 도구, 메뉴 경로, 체크리스트, 업무절차, 한계 및 작업공간 링크의 구조화 계약으로 검증한다.
- 외부 오류나 잘못된 응답은 추정 답변으로 대체하지 않고 로컬 미확인 안내를 반환한다.

## 비밀정보와 외부 전송 경계

- `.env`는 Git에서 제외하며 `.env.example`에는 키 값을 넣지 않는다.
- 환경 파일 로더는 Copilot 활성화 플래그와 Gemini API 키만 읽고 기존 프로세스 환경을 덮어쓰지 않는다.
- API 키를 응답, 로그, 근거 문서에 포함하지 않는다.
- 조직별 기밀·개인정보·수출통제 데이터의 외부 전송 허용 여부는 운영자가 별도로 승인해야 한다.

## 검증 범위의 한계

- 자동 설정 변경과 자동 분석 실행은 제공하지 않는다. 사용자가 안내를 검토하고 직접 실행한다.
- 실제 Gemini 호출은 API 키가 없는 테스트 환경에서 수행하지 않았으며, 구조화 출력과 실패 처리는 주입한 가짜 클라이언트로 검증했다.
- 모델 답변은 통계적 타당성이나 조직 절차 준수를 자동 보증하지 않는다.
