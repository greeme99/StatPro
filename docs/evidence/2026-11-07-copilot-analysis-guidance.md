# AI Copilot 분석 선택·설정 안내 증거

## 범위

- 오른쪽 보이기·감추기 패널과 작업공간별 추천 질문
- 현재 라우트 기반 DOE·SPC·FMEA·DMAIC 문맥
- 저장된 Analysis Run 및 DMAIC 프로젝트 식별 근거
- 관리도·DOE 설계 선택, 설정값, 현장 후속 절차와 관련 작업공간 링크
- 서버 소유 `CopilotProvider` 계약, 응답 공급자·근거 문서·한계 표시
- 서버 연결 또는 계약 실패 시 브라우저 로컬 결정 규칙 폴백

## 신뢰 경계

- 기본 답변은 제품에 구현된 기능과 공개 통계 원칙을 설명하는 서버 소유 결정론적 로컬 지식 공급자가 생성한다.
- 질문과 현재 근거 문맥은 로컬 API에만 전달되며 기본 공급자는 외부 모델·검색 서비스로 전송하지 않는다.
- Copilot은 분석 설정, 원본 데이터, 프로젝트 문서 또는 승인 상태를 자동 변경하지 않는다.
- 저장된 실행이 있는 경우 API에서 읽은 Run ID, 입력 digest, 엔진 버전, 경고 수를 답변 근거로 표시한다.
- 응답은 공급자 ID, 근거 문서 참조, 한계를 반환한다. 직접 대응하는 검토 규칙이 없으면 근거 부족을 명시한다.
- 승인된 사내 모델은 동일 `CopilotProvider` 경계에 별도 어댑터로 추가할 수 있으나 모델 기반 자유 생성, 외부 지식 검색, 조직별 SOP 검색과 설정 초안 적용은 이번 증분의 검증 범위가 아니다.

## 검증

- 패널 열기·닫기와 상태 보존
- 현재 SPC 작업공간 문맥 및 Xbar-R 설정 가이드
- 검사 수가 다른 불량률 질문의 p 관리도 추천과 정확한 라우트 연결
- 불변 Analysis Run 계약에 근거한 후속 조치 답변
- 서버 응답의 공급자·근거 출처 표시 및 작업공간 링크
- 빈 질문·미선언 필드 거부와 근거 없는 질문의 제한 응답
- `python -m unittest tests.test_api -v`: API 38개 테스트 통과
- `npm run check`: 웹 97개 테스트와 프로덕션 빌드 통과
