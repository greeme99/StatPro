# DMAIC 비용-편익 분석 작업공간 검증 근거

## 제공 범위

- Improve 단계에서 비용·편익 항목과 일회성·월간·연간 발생 주기를 입력한다.
- 분석 기간 기준 비용 합계, 편익 합계, 순편익, ROI 및 추정 회수기간을 계산한다.
- 비용-편익 문서는 프로젝트 개정과 함께 불변 저장되고, 개선안 선정·파일럿·근본원인 등 이용 가능한 이전 프로젝트 문서의 식별자·다이제스트를 참조한다.
- 통화·분석기간·입력 가정도 문서에 보존한다.

## 명시적 한계

- 계산값은 입력값을 합산한 시나리오이며 회계 실현, 할인율, 세금, 현금흐름 또는 투자 승인을 판정하지 않는다.
- 사용자는 재무·승인 체계에서 별도로 검토해야 하며 이 작업공간은 그러한 승인을 대체하지 않는다.
