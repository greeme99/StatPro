# DataStatPro 공개 웹 관찰 범위

관찰일: 2026-10-29

## 대상과 범위

- 대상: `https://datastatpro.com/`의 공개 페이지와 사용자가 제공한 화면 이미지.
- 관찰은 공개 문서와 화면에서 보이는 정보 구조·입력·출력 흐름에 한정한다.
- 로그인, 유료 기능, 비공개 API, 네트워크 요청, 클라이언트 번들, 내부 알고리즘은
  접근·수집·추정하지 않는다.

## 공개 페이지에서 확인한 사실

- 공개 페이지는 브라우저 기반의 안내형 통계 분석과 데이터 준비, 가정·진단, 시각화,
  보고서 흐름을 설명한다.
- 설명된 범주는 기술통계, t 검정, ANOVA, 카이제곱, 상관·회귀, 표본크기 계획,
  역학 측도, 시계열, 차트 및 출판 지향 보고서다.
- 공개 분석 색인은 14개 범주와 131개 도구를 안내하며, `데이터 준비 → 방법 선택 →
  결과·보고`의 상위 흐름을 제시한다. 데이터 관리, 기술/추론 통계, 상관, 고급 분석,
  시계열, 표본 크기, 신뢰구간, 역학, 시각화, 출판 보고 범주가 목록에 나타난다.
- 페이지는 정확한 추정량·진단·결측 처리·보고서 요구사항을 절차별로 확인해야 하며,
  다른 통계 도구의 완전한 대체라고 단정하지 않는다고 명시한다.

출처: [DataStatPro 공개 제품 페이지](https://datastatpro.com/) (2026-10-29 열람).

## 화면 이미지에서 확인한 사실

- 사용자가 제공한 화면은 분석 색인, 안내형 단계 흐름, DMAIC 도구상자, SPC와
  공정능력의 입력→규격/설정→계산→결과 흐름, 관리계획서·품질 지표·결함 분석의
  메뉴 배치를 보인다.
- 이 관찰은 화면 배치·브랜드·아이콘·문구·잠금/요금 정책을 복제하는 근거가 아니다.

## StatPro 적용 경계

- 공개 범주에서 현 StatPro 범위와 겹치는 DOE·SPC·FMEA/MSA는 기존 독립 구현을
  유지한다. 새 기능은 공개 통계 근거와 자체 요구사항으로 설계·검증한다.
- DMAIC는 독립 프로젝트 허브로, 분석 결과는 Analysis Run/FMEA Study의 식별자·ETag·
  digest만 참조한다.
- 상관·회귀·추론 통계, 품질 대시보드, 일반 결함 분석은 구현 증거가 생길 때까지
  `개발 예정`이다. 조직 경보·사용자 권한·실시간 데이터 계약은 `외부 정책 필요`다.
- 이 카탈로그는 StatPro에 대량의 기능을 일괄 추가하는 근거가 아니다. 각 후보는
  제조·품질·연구개발 사용자 가치, 공개 통계 근거, 독립 테스트 데이터, 데이터 모델,
  보고서·내보내기 계약을 충족하는 수직 증분으로만 검토한다.

## 알려진 미확인 사항

- `/app/dashboard`는 이 관찰 도구에서 직접 열리지 않아, 로그인 여부·실행 동작·
  백엔드 연동·데이터 보관·계산 로직은 확인하지 않았다.
