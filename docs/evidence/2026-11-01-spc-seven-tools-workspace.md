# SPC 7대 품질 도구 작업공간 근거와 구현 경계

## 1. 제공 문서에서 관찰한 내용

사용자 제공 문서 `Ref.doc/핵심 도구 7가지와 실제 활용 사례.pdf`의 4개 페이지를
이미지로 검토했다. 문서는 체크 시트, 관리 차트, 히스토그램, 산점도, 특성요인도,
파레토 차트, 계층화를 핵심 품질 도구로 설명한다. 관리 차트에는 중심선과 상·하 관리한계,
시간 순서의 일반원인·특별원인 구분, I-MR의 개별값·이동범위 역할이 포함된다.

문서의 관리도 분류 표는 계량형에 Xbar-R, Xbar-S, I-MR, 중앙값 관리도와 누적합·가중
평균 계열을, 계수형에 p, np, c, u를 제시한다. 신호 사례로 관리한계 밖의 점, 중심선 한쪽의
연속점, 2σ~3σ 영역 집중, 추세와 주기 변동을 제시한다.

## 2. StatPro 독립 구현

- `/spc`: 7대 도구를 현장 판단 순서인 `수집 → 분포·층별 → 관계·원인 → 우선순위 → 지속 감시`로 재구성한다.
- `/spc/control-charts`: 데이터 유형을 계량형과 계수형으로 먼저 나눈 뒤 현재 구현된 관리도 설정 화면으로 연결한다.
- 계량형: Xbar-R, Xbar-S, I-MR, EWMA, CUSUM.
- 계수형: p, np, c, u, Laney P′/U′, 희귀사건 G/T.
- 각 카드에는 적용 시점과 선택 기준을 표시하고, 계수형 선택은 URL query로 설정 화면까지 보존한다.

체크 시트는 `/spc/tools/check-sheet`에서 문서 생성, 현장 기록, 분류별 빈도·비율 집계와
파레토 입력 데이터 생성까지 실제로 실행한다. 불변 revision·digest와 저장소 version을 분리해
감사 추적과 동시 수정 충돌을 보존하며, 결과는 공통 ResultBundle 경계를 사용한다.

현재 독립 실행 엔진이 없는 히스토그램·계층화·산점도·특성요인도·일반 파레토는 통계 결과를
가장하지 않는다. 해당 화면은 현장 적용 순서와 기존 작업표·관리도 작업공간 연결을 제공하는
안내 작업공간이며, 후속 구현도 같은 ResultBundle 경계를 사용한다.

## 3. Minitab 증거와의 분리

이 PDF는 품질 도구의 일반 설명 자료이며 Minitab 14의 UI, 기본값, 계산식, 명령 또는 런타임
동작을 증명하지 않는다. 기존 Minitab 정적 증거와 StatPro 관리도별 공개 통계 근거는 각 관리도
evidence 문서에서 별도로 유지한다. 이 증분은 제공 문서의 정보구조를 참고한 독립 UI·Workflow
구현이며 Minitab 동등성을 주장하지 않는다.

## 4. 확인할 후속 범위

- 중앙값 관리도는 현재 엔진에 없으므로 실행 카드로 노출하지 않았다.
- 히스토그램·계층화·산점도·특성요인도·일반 파레토의 저장 모델·분석 엔진·ResultBundle은
  후속 수직 증분이다.
- 체크 시트의 CSV·Excel 입출력, 분류 마스터와 FMEA 결함 모드 연결은 후속 범위다.
- 모든 관리도에 대한 PDF·Excel·PNG·SVG 출력 일관화는 별도 보고서 범위다.
