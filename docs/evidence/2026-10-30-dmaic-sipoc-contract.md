# DMAIC SIPOC 불변 문서 계약 근거

## 범위

- 사용자 제공 화면은 SIPOC에 프로젝트명, 설명, 공정 시작·종료 경계와
  공급자·입력·공정·출력·고객을 기록하는 화면 구조 후보를 제시한다.
- 이 증분은 그 화면을 복제하거나 외부 서비스의 구현을 재사용하지 않는다.
  독립적인 로컬 API 계약과 불변 개정 문서만 구현한다.

## 구현된 계약

- `DmaicSipocMap`은 시작/종료 공정 경계 및 SIPOC 각 목록을 보관한다.
- 저장 시 각 목록은 비어 있지 않은 항목으로 검증하고, 프로젝트에는 전문 대신
  문서 ID·개정·digest 참조만 저장한다.
- 같은 프로젝트의 다음 SIPOC 저장은 새 문서와 `parent_digest`를 만들고, 기존
  문서는 변경하지 않는다.
- API는 다음을 제공한다.

  - `POST /v1/dmaic-projects/{project_id}/sipoc-maps`
  - `GET /v1/dmaic-projects/{project_id}/sipoc-maps/{document_id}`

- POST는 프로젝트의 `expected_storage_version`을 확인하며 불일치하면 HTTP 409로
  실패한다. 다른 프로젝트에 속한 문서는 조회하지 못한다.

## 검증 및 제한

- 도메인 테스트는 불변 개정 사슬, 전문 미중복, digest 역직렬화를 검증한다.
- API 테스트는 저장, 조회, 프로젝트 참조, 낙관적 버전 충돌을 검증한다.
- SIPOC 입력 화면, 파일 내보내기, 조직 ID·권한 수명주기 연동은 아직 구현하지
  않았으며 UI에는 `개발 예정`으로 표시한다.
