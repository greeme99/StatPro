# SPC 희귀사건 G/T 관리도 증분 근거 기록

## 범위

이 증분은 StatPro의 독립 G/T 희귀사건 관리도를 추가한다. G는 사건 자체를 제외한
기회 수(0 이상 정수), T는 사건 간 양의 시간·거리·사용량을 입력받는다.

## 공개 통계 근거

- SAS/QC `RAREEVENTS` 절차 문서는 기하분포와 지수분포의 누적분포함수 꼬리 확률로
  희귀사건 관리도의 확률 한계를 정의한다.
- 이 구현은 기본 꼬리 확률 0.005를 양쪽에 적용한다. T는 Phase I 평균 간격을 지수분포
  scale로 사용해 LPL·중앙값·UPL을 계산한다. G는 같은 입력 규약에서
  `p = 1 / (평균 기회 수 + 1)`을 추정하고, 이산 기하분포의 보수적 정수 분위수를 쓴다.

## 구현 및 보존 정보

- `spc.g_chart`, `spc.t_chart` ResultBundle은 간격별 통계량, 중앙값·LPL·UPL, 신호,
  입력 digest, 확률모형, 꼬리 확률 및 공개 provenance를 보존한다.
- API와 CLI는 G/T의 입력 계약을 분리한다. G는 정수 기회 수, T는 양의 연속 간격만
  수용한다.
- 화면은 `관리도 종류 선택 → 데이터 입력·검증 → 분석 결과 표시 → 결과 출력` 흐름을
  사용하며 차트와 접근 가능한 간격 표를 함께 제공한다.

## 경계와 미확인 사항

- 이 구현은 제공된 Minitab 14 바이너리의 G/T 화면, 계산식, 기본값, 세션 명령 또는
  출력 형식을 관찰하거나 재현하지 않았다. Minitab 제품과의 동등성은 주장하지 않는다.
- 현재는 입력 자료에서 Phase I 모수를 추정한다. 검증된 과거 모수를 쓰는 Phase II
  희귀사건 계약과 실시간 수집은 후속 범위다.
