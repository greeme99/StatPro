# SPC 일반 파레토 분석 근거

## 범위

StatPro의 체크 시트 집계 또는 사용자가 입력한 분류별 빈도·비용·손실을 하나의 비교 척도로
정렬하고, 구성비와 누적 기여도를 계산하는 일반 파레토 분석을 추가한다. 결과는 공통
`ResultBundle`과 Analysis Run으로 보존하며 전용 차트와 접근 가능한 결과 표를 함께 제공한다.

## 공개 통계 근거

- NIST/SEMATECH e-Handbook은 파레토 도표를 빈도순 막대와 누적선을 결합해 중요한 문제
  범주를 식별하는 그래픽 기법으로 설명한다.
  <https://www.itl.nist.gov/div898/handbook/eda/section3/pareto.htm>

## 구현 계약

- 값은 빈도, 비용 또는 손실 중 사용자가 선택한 하나의 비교 가능한 척도여야 한다.
- 빈 분류와 음수 값은 거부하고, 전체 합계가 0인 입력은 분석하지 않는다.
- 동일한 분류명은 분석 소유 경계에서 한 번 합산하고 값 내림차순·분류명 오름차순으로
  결정론적으로 순위를 정한다.
- 누적 기준을 처음 넘기는 분류까지 우선 조사 대상으로 포함한다.
- 연결된 체크 시트의 문서 ID와 스냅샷 digest를 Analysis Run에 보존한다.
- 누적 기준은 조사 순서를 좁히는 운영 기준이며 원인 또는 인과관계의 증거가 아니다.

## Minitab 14 증거와 미확인 범위

- 이 증분의 계산식과 UI 계약은 공개 NIST 근거를 사용한 독립 구현이다.
- Minitab 14 정적 문자열 또는 동적 화면을 이 증분의 계산식·기본값·표현 동등성 근거로
  사용하지 않았다. Minitab 14의 범주 병합, 동점 처리, 기본 누적 기준과 출력 형식은 미확인이다.
- 특성요인도·5 Why 자동 연결과 revision형 DMAIC Pareto 문서는 후속 범위다. 현재는 체크 시트
  스냅샷 또는 직접 입력에서 재현 가능한 Analysis Run을 만든다.

## 검증

- 엔진 시험은 중복 분류 합산, 결정론적 순위, 누적률, 기준 교차 분류 포함, 원천 추적,
  음수·0 합계 거부를 확인한다.
- API 시험은 `/v1/analysis-runs/pareto` 생성·저장·재조회와 원천 스냅샷 식별값 보존을 확인한다.
- 웹 시험은 예제 데이터 입력, 요청 계약, 전용 결과 차트와 접근 가능한 표를 확인한다.
