# DMAIC 프로젝트·헌장 불변 계약

## 구현 근거

프로젝트 사용자가 제공한 DMAIC 화면 구조는 프로젝트 헌장에 프로젝트 정보, 범위,
성공지표, 팀, 예산, 이정표, 위험과 가정/제약을 분리해 기록하도록 제안한다. 이 문서는
그 화면 제안의 저장 계약을 독립적으로 명시한다. 특정 상용 제품의 내부 형식 또는
계산 로직을 사용하지 않았다.

## 보존 규칙

- `DmaicProject`는 최신 헌장의 `document_id`, `revision`, `digest`만 보유한다.
- `DmaicCharter`는 각 저장마다 새 문서 ID로 생성되며 이전 헌장 digest를
  `parent_digest`로 보존한다.
- 이미 저장된 헌장은 수정하지 않는다. 프로젝트 갱신은 호출자가 제시한
  `expected_storage_version`이 현재 저장 버전과 일치할 때만 가능하다.
- API: 프로젝트 생성·조회·목록, 헌장 생성, 프로젝트 범위 헌장 조회.

## 검증 범위

`tests/test_dmaic.py`는 헌장 개정 체인과 이전 본문 보존을 검증한다.
`tests/test_api.py`는 저장 버전 충돌, 프로젝트의 참조 전용 표현, 헌장 조회를 검증한다.
VOC, SIPOC, 문제 정의, 이해관계자 분석, 웹 UI는 이 증분에 포함하지 않았다.
