# DMAIC 5 Why 질문·답변 사슬 증분 근거 기록

## StatPro 독립 구현

- 5 Why는 별도 추정 결과가 아니라 `DmaicRootCauseAnalysis`의 `five_whys` 방법에서
  저장하는 다섯 개의 질문·답변 단계다. 같은 문서에 문제, 원인 후보, 검증 원인, 다음
  조치, 프로젝트 문서 및 Analysis Run 근거가 함께 고정된다.
- 입력은 정확히 다섯 줄이어야 한다. 각 줄은 사용자가 현장 조사에서 작성한 질문과 답변을
  보존하며, StatPro는 사슬만으로 인과관계나 검증 완료를 자동 판정하지 않는다.
- UI는 5 Why를 선택했을 때만 사슬 입력을 보이고, 검증 원인 입력과 분리된 안내를
  제공한다. 저장은 새 프로젝트·근본원인 문서 revision을 만든다.

## 검증과 경계

- 도메인 테스트는 다섯 단계 사슬의 digest 왕복·프로젝트 참조와 단계 수 거부를 검증한다.
- API 회귀는 기존 DMAIC 저장 계약과의 호환성을 확인한다. 기존 사슬 없는 root cause
  문서의 digest는 변경하지 않는다.
- 5 Why는 조사 구조화 도구다. 현장 확인, 통계 검증, 특성요인도, 파레토 또는 DOE 없이
  원인을 입증하거나 CAPA/규제 준수를 판단하지 않는다.
