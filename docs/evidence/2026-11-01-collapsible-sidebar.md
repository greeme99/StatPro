# 접이식 사이드 메뉴 증거

## 관찰과 요구사항

- 사용자 제공 화면은 메뉴가 접힐 때 아이콘 레일을 유지하고 현재 메뉴를 강조한다.
- 사용자는 명시적 보이기·감추기 버튼과 포인터 접근 시 메뉴명 표시를 요청했다.

## 독립 구현

- `AppShell`이 확장 상태를 소유하고 `statpro-sidebar-collapsed` 로컬 키에 선택을 저장한다.
- 접힌 상태는 64px 토큰 너비를 사용하고 본문 여백을 같은 상태에서 파생한다.
- 메뉴 이름은 `한국어 (English)` 형식이며 hover와 keyboard focus에서 같은 툴팁을 노출한다.
- `aria-expanded`, 링크별 접근성 이름, 현재 경로의 `aria-current`를 보존한다.
- 1024px 미만은 저장된 선택이 없을 때만 접힌 상태로 시작하며 사용자가 다시 펼칠 수 있다.

## 검증

- `npm run check`: UI 70/70 Pass, TypeScript 및 Vite 프로덕션 빌드 Pass.
- 인앱 브라우저 AX 트리에서 접힌 토글, 8개 한·영 메뉴 링크, 현재 홈 경로와 본문 구조를 확인했다.

## 제한

- 768px 미만은 기존 제품 계약에 따라 지원하지 않고 화면 폭 안내를 표시한다.
