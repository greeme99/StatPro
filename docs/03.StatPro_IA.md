# StatPro 정보구조도 (IA) V1.5

> 2026-11-20 현재 구현·목표 기준 갱신. 전체 메뉴는 제품의 최종 구조를 보여 주되, 시작할 수
> 없는 기능은 `개발 예정` 또는 `외부 정책 필요` 상태로 명시한다. 이 문서는
> 현재 제품 구현과 향후 범위를 구분하며, 특정 상용 통계 제품의 UI를 복제하지 않는다.

## 1. 제품 메뉴

```text
StatPro
├─ 홈
│  ├─ 핵심 작업공간: DOE · SPC · FMEA
│  ├─ 최근 작업·분석 실행
│  ├─ DMAIC 개선 프로젝트
│  └─ 학습 리소스
├─ 작업표 및 데이터
│  ├─ 작업표 목록                         [구현됨]
│  ├─ 데이터 가져오기                     [구현됨: CSV, XLSX 첫 시트 및 선택 시트 값 전용, 평면 scalar Parquet, SQLite 지정 일반 테이블]
│  ├─ 변수·데이터 관리                    [구현됨: 셀 편집·필터·정렬·열 선택·열 이름 변경·파생 열]
│  ├─ 작업표 조인                         [구현됨: 단일 키 내부 조인, 오른쪽 작업표 digest 추적]
│  └─ 데이터 내보내기                     [구현됨: 현재 revision CSV]
├─ 실험계획법(DOE)
│  ├─ 새 실험 설계                        [구현됨: 완전/부분/분할구/선별/반응표면]
│  ├─ 설계 실행 및 결과 재조회             [구현됨: Analysis Run 이력]
│  ├─ 설계 분석                           [구현됨: ANOVA·잔차·Pareto]
│  ├─ 반응표면 및 최적화                  [구현됨: 등고선·Desirability]
│  ├─ 블록·폴드오버                       [구현됨]
│  └─ DOE 결과 및 보고서                  [구현됨: HTML·PDF·XLSX·Figures·ZIP]
├─ 통계적 공정관리(SPC)
│  ├─ 관리도 선택                         [구현됨: 계량형/계수형]
│  ├─ 데이터 입력·검증                     [구현됨]
│  ├─ 계량형 관리도                       [구현됨: I-MR·Xbar-R·Xbar-S]
│  ├─ 계수형 관리도                       [구현됨: p·np·c·u·Laney P′/U′]
│  ├─ 누적합·EWMA 관리도                  [구현됨]
│  ├─ 희귀사건 G/T 관리도                 [구현됨]
│  ├─ 공정능력 분석                       [구현됨: 정규·경험적 비정규]
│  ├─ 정규성 진단 & 선형 회귀             [구현됨: Jarque-Bera, OLS]
│  ├─ 측정시스템 분석(MSA)                [구현됨: 교차/중첩/REML Gage R&R, 편의·선형성, 속성 일치도]
│  └─ SPC/MSA 결과 및 보고서              [구현됨: 화면·표·신호, MSA HTML/PDF/XLSX/SVG 보고서]
├─ 고장 형태 및 영향 분석(FMEA)
│  ├─ FMEA 연구 목록                      [구현됨]
│  ├─ 공정 흐름도                         [구현됨]
│  ├─ PFMEA 분석                          [구현됨]
│  ├─ 관리계획서                          [구현됨]
│  ├─ 조치·검토·승인                      [구현됨]
│  ├─ 로컬 계정 상태·직무분리             [구현됨: 선택형 정책]
│  ├─ 기업 IdP·MFA·계정 발급              [외부 정책 필요]
│  └─ FMEA 보고서                         [구현됨]
├─ 개선 프로젝트(DMAIC)                   [구현됨: Define·Measure·Analyze·Improve·Control 5단계 개정 관리]
│  ├─ 정의(Define)                           [구현됨: 헌장·VOC·SIPOC·문제정의·이해관계자 불변 개정]
│  ├─ 측정(Measure)                          [구현됨: 측정 계획 불변 개정 및 MSA/SPC/능력 Run 근거 연결]
│  ├─ 분석(Analyze)                          [구현됨: 근본원인·특성요인도·5 Why·파레토·방법 선택 도우미]
│  ├─ 개선(Improve)                          [구현됨: DOE 연결, 개선안 선정, 파일럿, 비용편익, 실행계획 불변 개정]
│  ├─ 관리(Control)                          [구현됨: 관리계획서·SPC·공정능력·품질지표·결함분석 인수인계]
│  └─ DMAIC 종합 보고서                      [구현됨: Word (.docx) 및 PDF 내보내기]
├─ 결과 및 보고서
│  ├─ 분석 실행 이력                      [구현됨]
│  ├─ DOE 보고서 내보내기                 [구현됨: HTML·PDF·XLSX·JSON·CSV·SVG Figures·ZIP]
│  ├─ MSA 보고서 내보내기                 [구현됨: HTML·PDF·XLSX·SVG]
│  ├─ DMAIC 종합 보고서 내보내기          [구현됨: Word .docx, PDF]
│  ├─ DOE 고객·규제 검토 양식              [구현됨: 검토 시작점]
│  └─ 조직별 승인 양식                     [외부 정책 필요]
├─ AI Copilot 및 현장 규칙
│  ├─ AI Copilot 패널                     [구현됨: 전역 패널, 모델선택(auto/rulebase/exaone/codex), 폴백단계진단]
│  ├─ 현장 Rule 카탈로그                  [구현됨: 제품/현장 상황별 가이드, 키워드 검색]
│  └─ 사용자 정의 규칙 관리               [구현됨: 노하우/문서(TXT, MD, CSV) 업로드 및 직접 등록]
├─ 증거·감사 정보                          [구현됨]
├─ 계산 및 도우미
│  ├─ 공정능력 비교                       [구현됨]
│  ├─ 관리한계 점검                       [구현됨]
│  ├─ 실험 실행 수 계산                   [구현됨]
│  ├─ 가설검정·표본수 계획                 [구현됨: 독립·대응·다집단 평균 및 단일/두 비율 비교·검정력·표본수]
│  └─ 분석 선택 가이드                    [구현됨: 질문·결과척도·자료 구조]
└─ 도움말
   ├─ 단계별 설정                         [구현됨]
   ├─ 통계 방법·근거                      [구현됨]
   └─ 제한사항·버전 정보                  [구현됨]
```

`부분 구현`은 일부 흐름만 사용할 수 있음을 뜻하며, 사용자는 메뉴에서 해당
한계를 확인할 수 있어야 한다. `개발 예정` 항목은 활성 링크가 아니라 설명 패널로
연결한다.

## 3. 이동 흐름

```text
홈 → 빠른 시작 → DOE/SPC/FMEA 작업공간 → 설정 → 분석 실행 → 결과 및 보고서

SPC 분석 결과 → 현장 조치와 증적 연결 → FMEA 관리계획 또는 DMAIC 측정 근거 → 서버 재검증 후 revision 기록
개선 프로젝트(DMAIC) → 정의(헌장·VOC·SIPOC·문제정의·이해관계자) → 측정 계획 → 분석 실행/FMEA 연구 근거 연결 → 개선(선정·파일럿·비용편익·실행계획) → 관리 인수인계 → 종합 보고서(DOCX/PDF)
SPC → 7대 도구 Workflow 선택 → 관리도이면 계량형/계수형 분류 → 하위 관리도 선택 → 데이터 입력·검증 → 분석 실행 → 결과 표시·내보내기
홈 → 최근 작업 → 분석 결과 또는 FMEA 연구
FMEA 연구 → 공정흐름 → PFMEA → 관리계획서 → SPC/MSA 실행 증거 → 검토·승인
전역 → AI Copilot 패널 열기 → 상황 질문 또는 룰 선택 → 워크플로우/체크리스트 확인 → 작업공간 바로가기
개발 예정 메뉴 → 개발 예정 안내 → 가장 가까운 구현 기능 또는 도움말
```
