## 3. 이동 흐름

```text
홈 → 프로젝트 → 워크시트 → 분석 설정 → 분석 결과
                    ↘ FMEA 목록 → FMEA 편집
분석 결과 → DetailDrawer → 이슈 등록 → FMEA/조치 근거 연결
```

## 4. 핵심 데이터 구조

| 엔티티 | 주요 필드 |
|---|---|
| Project | id, name, revision, createdAt, updatedAt |
| Dataset | id, sourceDigest, normalizedDigest, source, schema, rowCount |
| Worksheet | id, projectId, baseDatasetDigest, revision, parentDigest, columns, transformations |
| AnalysisDefinition | id, type, inputBindings, parameters, engineVersion |
| AnalysisRun | id, definitionId, inputDigests, status, startedAt, completedAt |
| ResultBundle | runId, tables, plots, diagnostics, warnings, provenance |
| FmeaStudy | id, projectId, type, standardVersion, revision, parentDigest, status |
| FailureAnalysis | id, structureElement, function, requirement, mode, effect, cause, controls, initial/current ratings |
| RecommendedAction | id, failureAnalysisId, owner, dueDate, status, result, evidenceRefs |
| AuditEvent | sequence, eventType, actor, occurredAt, details |

분석과 FMEA는 `CONTEXT-MAP.md`에 정의된 immutable Evidence Reference로만 연결한다.
