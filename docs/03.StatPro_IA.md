# StatPro 정보구조도 (IA) V1.1

> 2026-10-28 개정. 전체 메뉴는 제품의 최종 구조를 보여 주되, 시작할 수
> 없는 기능은 `개발 예정` 또는 `외부 정책 필요` 상태로 명시한다. 이 문서는
> 현재 제품 구현과 향후 범위를 구분하며, 특정 상용 통계 제품의 UI를 복제하지 않는다.

## 1. 제품 메뉴

```text
StatPro
├─ 홈
│  ├─ 빠른 시작
│  ├─ 최근 작업
│  ├─ 진행 중인 분석
│  └─ 조치·승인 알림
├─ 작업표 및 데이터
│  ├─ 작업표 목록                         [구현됨]
│  ├─ 데이터 가져오기                     [구현됨: CSV]
│  ├─ 변수·데이터 관리                    [부분 구현]
│  └─ 데이터 내보내기                     [개발 예정]
├─ 실험계획법(DOE)
│  ├─ 새 실험 설계                        [구현됨]
│  ├─ 설계 목록 및 실행                   [개발 예정]
│  ├─ 설계 분석                           [구현됨]
│  ├─ 반응표면 및 최적화                  [구현됨]
│  ├─ 블록·폴드오버                       [구현됨]
│  └─ DOE 결과 및 보고서                  [구현됨]
├─ 통계적 공정관리(SPC)
│  ├─ 관리도 선택                         [구현됨]
│  ├─ 계량형 관리도                       [구현됨]
│  ├─ 계수형 관리도                       [구현됨]
│  ├─ 누적합·EWMA 관리도                  [구현됨]
│  ├─ 희귀사건 관리도                     [개발 예정]
│  ├─ 공정능력 분석                       [구현됨]
│  └─ SPC 결과 및 보고서                  [부분 구현]
├─ 고장 형태 및 영향 분석(FMEA)
│  ├─ FMEA 연구 목록                      [구현됨]
│  ├─ 공정 흐름도                         [구현됨]
│  ├─ PFMEA 분석                          [구현됨]
│  ├─ 관리계획서                          [구현됨]
│  ├─ 조치·검토·승인                      [구현됨]
│  ├─ 기업 계정 연동·직무분리             [외부 정책 필요]
│  └─ FMEA 보고서                         [구현됨]
├─ 결과 및 보고서
│  ├─ 분석 실행 이력                      [구현됨]
│  ├─ DOE HTML·JSON·CSV 내보내기          [구현됨]
│  ├─ 그래프 이미지·PDF·고객 양식          [개발 예정]
```

`부분 구현`은 일부 흐름만 사용할 수 있음을 뜻하며, 사용자는 메뉴에서 해당
한계를 확인할 수 있어야 한다. `개발 예정` 항목은 활성 링크가 아니라 설명 패널로
연결한다.

## 3. 이동 흐름

```text
홈 → 빠른 시작 → DOE/SPC/FMEA 작업공간 → 설정 → 분석 실행 → 결과 및 보고서
홈 → 최근 작업 → 분석 결과 또는 FMEA 연구
FMEA 연구 → 공정흐름 → PFMEA → 관리계획서 → SPC/MSA 실행 증거 → 검토·승인
개발 예정 메뉴 → 개발 예정 안내 → 가장 가까운 구현 기능 또는 도움말
```

## 4. 핵심 데이터 구조

| 엔티티 | 주요 필드 |
|---|---|
| Project | id, name, revision, createdAt, updatedAt |
| Dataset | id, sourceDigest, normalizedDigest, source, schema, rowCount |
| Worksheet | id, projectId, baseDatasetDigest, revision, parentDigest, columns, transformations |
| AnalysisDefinition | id, type, inputBindings, parameters, engineVersion |
| AnalysisRun | id, definitionId, inputDigests, status, startedAt, completedAt |
| ResultBundle | runId, tables, plots, diagnostics, warnings, provenance |
| FmeaStudy | id, projectId, type, standardVersion, revision, parentDigest, status |
| FailureAnalysis | id, structureElement, function, requirement, mode, effect, cause, controls, initial/current ratings |
| RecommendedAction | id, failureAnalysisId, owner, dueDate, status, result, evidenceRefs |
| AuditEvent | sequence, eventType, actor, occurredAt, details |

분석과 FMEA는 `CONTEXT-MAP.md`에 정의된 immutable Evidence Reference로만 연결한다.
