# StatPro 정보구조도 (IA) V1.3

> 2026-11-02 개정. 전체 메뉴는 제품의 최종 구조를 보여 주되, 시작할 수
> 없는 기능은 `개발 예정` 또는 `외부 정책 필요` 상태로 명시한다. 이 문서는
> 현재 제품 구현과 향후 범위를 구분하며, 특정 상용 통계 제품의 UI를 복제하지 않는다.

`부분 구현`은 일부 흐름만 사용할 수 있음을 뜻하며, 사용자는 메뉴에서 해당
한계를 확인할 수 있어야 한다. `개발 예정` 항목은 활성 링크가 아니라 설명 패널로
연결한다.

## 3. 이동 흐름

```text
홈 → 빠른 시작 → DOE/SPC/FMEA 작업공간 → 설정 → 분석 실행 → 결과 및 보고서

SPC 분석 결과 → 현장 조치와 증적 연결 → FMEA 관리계획 또는 DMAIC 측정 근거 → 서버 재검증 후 revision 기록
개선 프로젝트(DMAIC) → 정의(프로젝트 헌장·고객의 소리·SIPOC 공정 맵·문제 정의·이해관계자 분석) → 측정 계획 → 분석 실행/FMEA 연구 근거 연결
SPC → 7대 도구 Workflow 선택 → 관리도이면 계량형/계수형 분류 → 하위 관리도 선택 → 데이터 입력·검증 → 분석 실행 → 결과 표시·내보내기
홈 → 최근 작업 → 분석 결과 또는 FMEA 연구
FMEA 연구 → 공정흐름 → PFMEA → 관리계획서 → SPC/MSA 실행 증거 → 검토·승인
개발 예정 메뉴 → 개발 예정 안내 → 가장 가까운 구현 기능 또는 도움말
```
