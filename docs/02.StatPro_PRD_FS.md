## 2. MVP 상세

### FN-002 워크시트

- 입력: UTF-8 CSV, 헤더, 선택적 타입 힌트
- 처리: 원본 byte digest 계산 → 타입 추론 → 결측 표시 → 정규화 digest 계산 → 불변 Dataset 생성 → revision형 Worksheet 생성
- 출력: 열 이름·타입·행 수·결측 수와 미리보기
- 규칙: 원본 위치는 Dataset 정규화 digest에 포함하지 않으며, Worksheet 편집은 부모를 변경하지 않고 새 revision을 생성한다.
- 타입: numeric/logical/datetime/text를 자동 추론하고 categorical은 명시적 타입 힌트로 지정한다.
- 예외: 중복 열 이름, 혼합 타입, 비정상 인코딩은 위치와 해결 방법을 포함한 오류를 반환한다.

### FN-004 I-MR

- 입력: 순서가 보존된 숫자 관측값 2개 이상, 선택적 목표 중심선
- 처리: 연속 관측값의 moving range, 평균 moving range, NIST 방식 3-sigma 한계를 계산한다.
- 출력: 개별값/이동범위 계열, 중심선, 한계, 한계 밖 신호, 가정과 경고
- 규칙: 결측은 0으로 대체하지 않는다. 기본값은 결측 구간에서 moving range를 끊는다.
- 예외: 유한 숫자 부족, 전체 상수인데 규칙 계산을 요청한 경우 명시적으로 처리한다.

### FN-004 Xbar-R

- 입력: 동일 크기 2–10의 rational subgroup가 2개 이상
- 처리: 부분군 평균/범위, grand mean, average range, 표준 A2/D3/D4 상수를 사용한다.
- 출력: Xbar/R 두 차트의 계열·중심선·한계·신호
- 예외: 부분군 크기가 다르거나 지원 범위 밖이면 실패하고 Xbar-S 전환을 안내한다.

### FN-004 p/np/c/u 속성 관리도

- 공통 입력: 시간 순서의 부분군별 부적합품 정수 개수와 양의 정수 표본 크기, 부분군 2개 이상
- p 처리: 전체 검사 수로 가중한 통합 부적합률을 중심선으로 사용하고 부분군별 표본 크기에 맞춘 이항 3σ 한계를 계산한다.
- np 처리: 모든 부분군의 표본 크기가 같을 때 부적합품 개수 척도의 이항 3σ 한계를 계산한다.
- 공통 출력: 부분군별 통계량·표본 크기·중심선·LCL/UCL·한계 이탈 신호, 통합 요약, 경고와 공개 출처
- 예외: 음수·비정수, 0 표본 크기, 부적합품 수가 표본 크기를 초과하는 입력을 tagged error로 거부한다. np의 가변 표본 크기는 p 전환을 안내한다.
- 확장: c/u는 동일한 속성 관리도 포인트 계약을 사용하되 포아송 계산 경계를 별도로 소유한다.
- c/u 처리: 동일 검사 기회의 c는 결점 수, 가변 검사 기회의 u는 단위당 결점 수에 포아송 3σ 한계를 적용한다.

### FN-005 정규 공정능력

- 입력: 숫자열, LSL/USL 중 하나 이상, 선택적 목표값과 부분군 정의
- 출력: Cp/Cpk/Pp/Ppk, 예상·관찰 불량, 히스토그램과 한계
- 규칙: 규격한계와 관리한계를 혼동하지 않도록 화면과 API 필드명을 분리한다.

### FN-006 Gage R&R Crossed

- 입력: 부품, 작업자, 반복 측정값
- 출력: 분산 성분, %Contribution, %Study Variation, ndc, 그래프와 진단
- 계산: 균형 2원 교차 ANOVA의 method-of-moments 분산성분을 사용한다.
- 정책: 음의 분산성분은 0으로 절단하되 원 추정값과 경고를 결과에 보존한다.
- 예외: 완전 교차가 아니거나 셀이 비었거나 반복 수가 불균형하면 tagged error로 실패한다.
- 현재 제한: 유의성 검정, 상호작용 풀링, REML, 비균형·nested 설계는 후속 범위다.

### FN-007 2수준 완전요인 DOE

- 입력: 2개 이상 요인과 low/high 수준, 반복·중심점·랜덤 시드
- 처리: -1/+1 코딩, 전체 조합, 선택적 반복/랜덤화
- 출력: 설계 행렬, run order, factor metadata
- 분석 출력: 효과·계수·ANOVA·잔차·예측
- 정규 일부요인: 사용자 생성식, 정의관계, 해상도와 주효과/2요인 별칭구조를 반환한다. 실행순서 응답은 주효과 별칭 대표항으로 분석하며 Pareto·잔차·별칭 해석을 함께 보존한다.
- Full foldover: 해상도 III 정규 fraction의 모든 부호를 반전한 mirror-image 실행을 추가해 주효과와 2요인 교호작용의 별칭을 끊는다. 2요인 교호작용끼리의 별칭은 남을 수 있다.
- 중앙합성설계: 2–6개 정량 요인에 full factorial, axial, center point를 결합하고 rotatable 또는 face-centered α를 제공한다. 응답 분석은 coded 선형·2요인 교호작용·제곱항의 완전 2차 모형, ANOVA, pure error/lack of fit, 잔차를 반환한다. 응답표면 탐색은 2차 계수행렬의 정상점과 canonical 고유값 분류, 선택한 두 요인의 bounded 격자·구간 극값·선형 보간 iso-response 등고선 선분을 반환하며 미선택 요인의 hold 값을 명시한다.
- Plackett–Burman: 2–47개 요인, 12/20/24/28/32/36/40/44/48회 선별설계, 반복·중심점·재현 가능한 무작위화를 제공한다.
- Plackett–Burman 분석: 실행순서 응답에서 직교 주효과를 추정하고, 잔차 자유도가 있으면 표준화 효과, 없으면 Lenth PSE 기준의 절대 효과 Pareto를 반환한다.
- 확인 흐름: 기준선을 넘은 요인은 독립 확인실험 후보와 응답 증가 방향으로만 제시하며 인과 효과로 확정하지 않는다.
- 선별 안전성: 모든 기본 행렬의 열 균형과 열쌍 직교를 검증하고 해상도 III 교호작용 혼입 및 확인 실험 필요성을 경고한다.

### FN-008 FMEA

- 입력: 구조/공정 단계, 기능, failure mode/effect/cause/control, S/O/D, 표준 버전
- 출력: Action Priority 또는 RPN, 권고 조치, 책임자, 기한, 전후 평가와 감사 이력
- 상태: Draft → In Review → Approved이며 구조 편집과 조치 완료는 Draft에서만 수행한다.
- 규칙: 각 변경은 부모 digest를 가리키는 새 Study Revision을 만들고 최초 평가를 재작성하지 않는다.
- 승인: 미완료 권고 조치가 있으면 승인을 차단한다.
- Action Priority: 정책 ID·표준 버전·정책 digest가 있는 외부 제공 매트릭스로 계산한다.
- AP 미산출 상태: `policy_not_supplied`와 `no_matching_entry`를 서로 다른 사유로 보존한다.
- 라이선스 경계: 독점 표준의 Action Priority 판정표는 제품 소스와 기본 데이터에 포함하지 않는다.
- RPN: S×O×D를 제공하지만 Action Priority의 대체물로 취급하지 않는다.

### FN-010 로컬 자동화 API

- 실행: 기본 `127.0.0.1` loopback에서만 수신하며 외부 인터페이스 bind를 거부한다.
- 분석: I-MR, Xbar-R, p/np, 정규 공정능력, 2수준 완전요인·정규 일부요인(해상도 III full foldover 포함)·Plackett–Burman 설계·응답 분석 DOE, 균형 교차 Gage R&R을 동일 코어 계약으로 실행한다.
- 저장: Analysis Run은 생성 후 불변이며 ID 재사용은 HTTP 409로 실패한다.
- 조회: 단건 ETag와 최대 100건 cursor pagination을 제공한다.
- 오류: 도메인 오류, 요청 계약 오류, 저장 충돌, 미존재를 구분된 code와 HTTP 상태로 반환한다.
- 보안: 요청 검증 오류는 사용자가 보낸 데이터 값을 반사하지 않고 필드 위치와 오류 유형만 반환한다.
- 현재 제한: 인증, TLS, 다중 프로세스 writer, 원격 bind는 지원하지 않는다.

## 3. 사용자 흐름

```text
프로젝트 생성 → 데이터 가져오기 → 데이터 품질 확인
  → 분석 선택 → 변수/옵션 지정 → 실행
  → 결과·가정·경고 검토 → 저장/리포트/후속 분석
```

```text
프로젝트 생성 → FMEA Study 생성 → 구조/기능/고장 분석
  → 위험평가 → 조치 할당 → 재평가 → 승인/보고서
```

## 4. 비기능 명세

- 100,000행 단일 열 I-MR 계산의 목표 응답시간은 일반 개발 PC에서 2초 이내다.
- 모든 결과 숫자는 원시 정밀도를 보존하고 표시는 사용자 포맷으로 분리한다.
- 계산 실패는 tagged error code, 사용자 메시지, 필드 위치를 제공한다.
- 프로젝트는 로컬 우선이며 네트워크 기능은 명시적으로 활성화한다.
- 변경 가능한 업무 객체는 revision과 감사 이벤트를 가진다.
