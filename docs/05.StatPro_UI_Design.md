# StatPro UI 디자인 시안 V1.0

## 1. 컨셉

제조 현장의 판단을 빠르게 만드는 데이터 중심 업무 화면이다. 장식보다 데이터, 상태, 원인과 다음 행동의 위계를 우선한다.

- 전역 `Work App Design System v1.0`을 변경 없이 상속한다.
- 브랜드 표면은 `--color-action`과 `--color-fill-brand`를 사용한다.
- 정상·주의·위험은 status semantic token과 텍스트/아이콘을 함께 사용한다.
- 요약 화면은 comfortable, 분석·테이블·FMEA는 compact density를 사용한다.

## 2. 타이포그래피와 수치

- 화면 제목: `h1`
- 섹션/차트 제목: `h2`
- 본문: `body`
- 데이터 셀: `data`
- 모든 통계 수치: tabular numerals
- 원시 계산 정밀도와 화면 반올림 형식을 분리한다.

## 3. 핵심 컴포넌트

| 컴포넌트 | StatPro 용도 |
|---|---|
| AppHeader | 제품·환경·프로젝트·테마·사용자 |
| SidebarNav | 데이터/분석/FMEA/리포트 이동 |
| FilterBar | 기간·공정·제품·라인 필터 |
| KpiCard | 신호, Cpk, Gage R&R, 미완료 조치 |
| ChartCard | 관리도, DOE 효과도, 분포·신뢰성 그래프 |
| DataTable | 워크시트, 결과표, FMEA 위험 테이블 |
| DetailDrawer | 결과 드릴다운, 신호·고장모드 상세 |
| Toast | 저장·실행·오류 피드백 |

모든 적용 가능한 컴포넌트에 default, hover, focus, active, disabled, loading, error, empty 상태를 구현한다.

## 4. 접근성

- WCAG 2.1 AA 대비
- 44px 이상 터치/클릭 대상
- 키보드 완전 조작과 skip link
- 차트 `role=img` 요약 및 원본 데이터 표
- 포커스 트랩이 있는 drawer/modal과 Esc/복귀 동작
- reduced-motion 설정 준수

## 5. 가정 결정

| 항목 | 초기 결정 | 재검토 시점 |
|---|---|---|
| 폰트 | Pretendard Variable + 시스템 fallback | 사내 배포 라이선스 검토 |
| 최소 폭 | 768px | 현장 모바일 요구 발생 시 |
| 차트 | Recharts | 100k+ 시계열/히트맵 구현 전 |
| 인쇄 | 결과 리포트에 print stylesheet 포함 | 보고서 템플릿 확정 시 |
| 갱신 | 사용자 실행 기반, 실시간 아님 | 설비 스트리밍 단계 |

## 6. 완료 기준

- 토큰 밖 raw 색·간격·radius 없음
- 한 화면 primary action 1개
- light/dark 및 comfortable/compact 동작
- loading/empty/error 상태와 200% 확대 확인
- 결측값을 0으로 보간하지 않음

## 7. 구현 상태 (2026-10-20)

- 구현: AppHeader, SidebarNav, KPI 카드, CSV Worksheet 가져오기·목록·타입 프로필·셀 편집, I-MR 설정 폼, 관리도, 원본 표, 계산 근거 DetailDrawer, FMEA 목록·생성·고장분석·검토요청 화면
- 상태: loading, empty, API error, validation error, disabled, light/dark
- 접근성: skip link, 의미 기반 입력 레이블, 차트 요약·대체 표, drawer focus trap/Esc/trigger 복귀
- 시각화 안전성: Y축 범위가 관측값뿐 아니라 UCL/LCL을 항상 포함하고 표시값은 두 자리로 제한
- FMEA 안전성: S/O/D·RPN과 AP를 구분하고, 고객 제공 정책이 없으면 AP를 `미계산`으로 명시
- 데이터 안전성: CSV 원본 byte digest와 정규화 digest를 분리하고, 셀 편집은 optimistic concurrency를 거친 새 immutable revision으로 저장
- 성능: Recharts를 별도 지연 로딩 chunk로 분리; 초기 앱 JavaScript 315.92kB, 차트 chunk 357.94kB (minified)
- 보류: Worksheet 필터·정렬·파생 열, DOE·MSA·공정능력 전용 결과 화면, FMEA 조치 완료·승인 UI, 리포트/인쇄
