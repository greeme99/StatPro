# StatPro UI 디자인 시안 V1.1

## 1. 컨셉

제조 현장의 판단을 빠르게 만드는 데이터 중심 업무 화면이다. 장식보다 데이터, 상태, 원인과 다음 행동의 위계를 우선한다.

- 전역 `Work App Design System v1.0`을 변경 없이 상속한다.
- 브랜드 표면은 `--color-action`과 `--color-fill-brand`를 사용한다.
- 정상·주의·위험은 status semantic token과 텍스트/아이콘을 함께 사용한다.
- 요약 화면은 comfortable, 분석·테이블·FMEA는 compact density를 사용한다.
- 모든 UI 문구는 한국어로 쓰며, 현장 약어는 최초 노출에서 한글명과 병기한다.
- 상용 구독·업셀을 연상시키는 잠금, 크레딧, `Pro` 표시는 사용하지 않는다.

## 1.1 화면 역할

| 화면군 | 사용자의 질문 | 주된 표현 | 구현 원칙 |
|---|---|---|---|
| 홈 | 지금 무엇을 해야 하는가? | 빠른 시작, 최근 작업, 조치 | 카드로 시작점을 제공 |
| 작업공간 | 어떤 업무 흐름을 수행하는가? | DOE/SPC/FMEA 단계와 상태 | 탭·진행 상태·표 중심 |
| 분석 설정 | 실행할 준비가 되었는가? | 입력, 검증, 완료 조건 | 한 개의 primary action |
| 결과 및 보고서 | 무엇을 발견했고 증명할 수 있는가? | 차트, 표, 경고, 근거 | Run·digest·엔진 버전 보존 |
| 개발 예정 | 지금 무엇을 쓸 수 있는가? | 범위, 의존성, 대체 경로 | 비활성 실행 버튼 금지 |

## 2. 타이포그래피와 수치

- 화면 제목: `h1`
- 섹션/차트 제목: `h2`
- 본문: `body`
- 데이터 셀: `data`
- 모든 통계 수치: tabular numerals
- 원시 계산 정밀도와 화면 반올림 형식을 분리한다.

## 5.1 한국어 UI 표준 용어

화면에는 아래 **표준표현**을 사용하고, 괄호 안 표현은 코드·기술 문서 또는
외부 연동 맥락 외에는 사용자 화면에 노출하지 않는다.

| 표준표현 (비권장 표현) | 적용 범위 |
|---|---|
| 홈 (Dashboard) | 제품 첫 화면과 요약 현황 |
| 작업공간 (Workspace) | DOE·SPC·FMEA 업무 진입과 진행 화면 |
| 분석 실행 (Run) | 불변 Analysis Run 기록과 결과 식별 |
| FMEA 연구 (Study) | FMEA 개정·검토·승인 단위 |
| 관리계획서 (Control Plan) | PFMEA 연결 관리 항목 |
| 단계별 설정 (Guided workflow) | 순서형 분석 준비 흐름 |
| 빠른 설정 (Quick setup) | 숙련자를 위한 직접 입력 흐름 |
| 결과 및 보고서 (Results & Reports) | 실행 결과, 근거, 내보내기 |
| 사용하지 않음 (Unlock / Pro) | 상업형 잠금·업셀 문구 |

버튼은 동작을 명확히 표현한다. 예: `새 실험 만들기`, `실행표 생성`,
`분석 실행`, `보고서 내보내기`, `승인 검토 시작`.

## 5.2 DOE 작업공간 UX

- 상단은 경로, 실험명, 개정/상태, 도움말, 보고서 링크로 구성한다.
- 탭은 `설계 및 계획 → 실행 데이터 → 분석 → 결과 → 최적화 → 근거` 순으로
  유지한다. 아직 생성되지 않은 실행표 이후 탭은 잠그지 않고, 필요한 선행 조건을
  안내한다.
- 인자와 반응은 표로 편집한다. 각 표의 빈 상태는 각각 `인자 추가`, `반응 추가`라는
  단일 행동을 제공한다.
- 실행표 생성 전에는 예상 실행 수, 블록, 반복, 무작위화, 별칭 또는 해상도 경고를
  한 요약 패널에 보인다.
- 설계 유형 선택에는 현재 가능한 유형만 기본 목록에 둔다. 미구현 유형은 `개발 예정`
  표시를 가진 카탈로그 항목으로 분리한다.

## 5.3 구현 상태 표현

| 상태 | 의미 | UI 행동 |
|---|---|---|
| 구현됨 | 로컬 엔드투엔드 흐름 가능 | 기능으로 이동 |
| 부분 구현 | 핵심 흐름은 가능하나 명시된 한계 존재 | 기능으로 이동 + 한계 안내 |
| 개발 예정 | 실행 불가 | 안내 화면 + 대체 경로 |
| 외부 정책 필요 | 조직 정책/IdP가 필요 | 준비 항목과 책임 범위 안내 |

## 6. 완료 기준

- 토큰 밖 raw 색·간격·radius 없음
- 한 화면 primary action 1개
- light/dark 및 comfortable/compact 동작
- loading/empty/error 상태와 200% 확대 확인
- 결측값을 0으로 보간하지 않음
