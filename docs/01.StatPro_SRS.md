## 0. 현재 구현 기준선

홈(Home)에서 DOE·SPC·FMEA 작업공간으로 진입하고, 각 작업공간은 Workflow의 입력·검증·실행·결과·출력 단계를 제공한다. DMAIC는 정의·측정·분석·개선·관리의 업무 맥락에서 불변 개정 문서와 DOE, SPC, MSA, FMEA, 품질 도구의 실행 근거를 연결한다. AI Copilot은 Rulebase를 먼저 적용하고, 명시적으로 활성화한 외부/로컬 모델을 제한된 폴백으로만 사용한다. 구현 상태의 세부 매핑은 `docs/03.StatPro_IA.md`, `docs/08.StatPro_Menu_UI_Proposal.md`, `docs/10.StatPro_AI_Copilot_Rule_Catalog.md`를 기준으로 한다.

## 2. 배경 및 목표

현장 데이터는 스프레드시트, 개별 통계 도구, 문서형 FMEA에 흩어져 있어 계산 재현성, 변경 추적, 자동화가 어렵다. StatPro는 데이터부터 분석, 시각화, 리포트와 위험조치까지 연결한다.

정량 목표:

- 반복 분석 준비 시간을 기존 수작업 대비 50% 이상 단축
- 동일 입력·옵션·엔진 버전의 결과 재현율 100%
- 핵심 통계 테스트 벡터의 기준값 허용오차 통과율 100%
- 분석 결과의 입력·변환·옵션 출처 추적 가능률 100%
- 주요 업무를 키보드만으로 완료 가능한 화면 비율 100%

## 4. 범위

### MVP

- 프로젝트/워크시트/분석 실행/결과 공통 모델
- CSV 데이터 가져오기, 워크시트 셀 편집·필터·정렬·선택형 숫자 파생 열 및 현재 revision CSV 내보내기
- I-MR, Xbar-R, Xbar-S, 시작 시점 보정 EWMA, 양측 tabular CUSUM, p/np/c/u, Laney P′/U′ 및 G/T 희귀사건 관리도
- 정규·경험적 비정규 공정능력, 교차·중첩 Gage R&R, 속성 일치도 Wilson 신뢰구간
- 2수준 완전/일부요인, Plackett–Burman, 중앙합성, Box–Behnken, 반응표면·다중응답 최적화 DOE
- ResultBundle 표·차트·HTML/JSON/CSV/SpreadsheetML 출력 및 지원 차트 이미지
- FMEA/PFMEA, AP 외부 정책 경계, 로컬 재인증·직무분리·감사 이력
- DMAIC Define·Measure·Analyze·Improve·Control의 불변 문서와 실행 근거 연결

### 후속 범위

- XLSX/Parquet/SQL 가져오기, 조인·임의 수식, 기초·추론 통계, 상관·회귀·시계열·신뢰성
- 고급 DOE, 다변량·부분군·one-sided/ARL 설계 등 추가 SPC, 실시간 수집, R/Python SDK
- 파일 생성형 PDF/XLSX, 조직별 전자승인 양식, 실제 IdP/MFA/계정 수명주기 연동 및 운영 검증

### 제외 범위

- 타사 바이너리·화면·리소스·비공개 API 복제
- 라이선스 우회 또는 보호 기능 회피
- 모바일 전용 UI

## 5. 성공 기준

- NIST 및 독립 공개 구현의 기준 데이터와 수치 교차검증
