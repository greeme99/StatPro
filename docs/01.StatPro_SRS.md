# StatPro 요구사항 명세서 (SRS) V1.0

## 1. 프로젝트 개요

- 프로젝트명: StatPro
- 작성일: 2026-10-19
- 목적: 전자 제조기업의 제조·품질·연구개발 분석을 하나의 재현 가능한 플랫폼에서 수행한다.
- 대상 사용자: 품질 엔지니어, 공정 엔지니어, 연구개발 엔지니어, 통계 전문가, 품질 관리자

## 2. 배경 및 목표

현장 데이터는 스프레드시트, 개별 통계 도구, 문서형 FMEA에 흩어져 있어 계산 재현성, 변경 추적, 자동화가 어렵다. StatPro는 데이터부터 분석, 시각화, 리포트와 위험조치까지 연결한다.

정량 목표:

- 반복 분석 준비 시간을 기존 수작업 대비 50% 이상 단축
- 동일 입력·옵션·엔진 버전의 결과 재현율 100%
- 핵심 통계 테스트 벡터의 기준값 허용오차 통과율 100%
- 분석 결과의 입력·변환·옵션 출처 추적 가능률 100%
- 주요 업무를 키보드만으로 완료 가능한 화면 비율 100%

## 4. 범위

### MVP

- 프로젝트/워크시트/분석 실행/결과 공통 모델
- CSV 데이터 가져오기
- I-MR, Xbar-R, Xbar-S, 시작 시점 보정 EWMA, 양측 tabular CUSUM 및 이항·포아송 속성 p/np/c/u와 Laney P′/U′ 관리도
- 정규 공정능력
- Gage R&R Crossed
- 2수준 완전요인·정규 일부요인 DOE와 Plackett–Burman 선별설계·응답 분석
- 결과 표·기본 차트·JSON 내보내기
- FMEA 핵심 데이터 모델

### 후속 범위

- 고급 DOE, stage·다변량·희귀사건 등 고급 SPC, 신뢰성, 시계열, 다변량, AutoML, R/Python SDK, 실시간 수집

### 제외 범위

- 타사 바이너리·화면·리소스·비공개 API 복제
- 라이선스 우회 또는 보호 기능 회피
- 모바일 전용 UI

## 5. 성공 기준

- NIST 및 독립 공개 구현의 기준 데이터와 수치 교차검증
- 분석 계약 테스트가 UI/API/배치에서 동일 결과를 확인
- 결측·상수열·부족 표본·비정상 부분군에 대한 명시적 오류/경고
- 핵심 화면 접근성 자동검사 및 키보드 시나리오 통과
