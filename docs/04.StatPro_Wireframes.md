# StatPro 와이어프레임 V1.1

## 공통 앱 셸과 메뉴 상태

```text
┌ Header: StatPro | 현재 작업표 | 테마 | 사용자 ───────────────────────────┐
├ Sidebar ┬ Main ────────────────────────────────────────────┬ 알림/이슈 ┤
│ 홈      │ 경로 · 화면 제목 · 상태 배지                     │ 조치·승인 │
│ 작업표  │                                                   │           │
│ DOE     │ 화면별 주 작업                                   │           │
│ SPC     │                                                   │           │
│ FMEA    │                                                   │           │
│ 결과 및 │                                                   │           │
│ 보고서  │                                                   │           │
│ 계산 및 │                                                   │           │
│ 도우미  │                                                   │           │
│ 도움말  │                                                   │           │
└─────────┴───────────────────────────────────────────────────┴───────────┘
```

- 메뉴의 상태 배지는 `구현됨`, `개발 예정`, `외부 정책 필요` 중 하나다.
- `개발 예정` 메뉴는 분석을 실행하는 것처럼 보이는 버튼을 제공하지 않는다.
- 화면의 상태 배지는 색만으로 구분하지 않으며 아이콘과 텍스트를 함께 쓴다.

## SCR-033 DOE 작업공간

```text
┌ 홈 > 실험계획법(DOE) > 실험명 ────────────────────────────────┐
│ 실험계획법(DOE)  [설계 중]             [도움말] [보고서]       │
├ [설계 및 계획] [실행 데이터] [분석] [결과] [최적화] [근거] ──┤
│ ① 실험 목적 ─ ② 인자·반응 ─ ③ 설계·블록 ─ ④ 실행표 ─ ⑤ 분석 │
├──────────────────────────────────────────────────────────────┤
│ 설계 유형 [완전요인 ▼]  [설계 상세 보기]                      │
│ 인자 설정: 이름 | 유형 | 낮은 수준 | 높은 수준 | 단위          │
│ 반응 설정: 이름 | 목표 | 규격 하한 | 규격 상한 | 기준          │
│ 실행 조건: 반복 | 무작위화 | 블록 | 중심점                    │
│ 완료 조건: 인자 2개 이상 · 반응 1개 이상                       │
│                                             [실행표 생성]     │
└──────────────────────────────────────────────────────────────┘
```

- `실행표 생성`은 화면당 유일한 primary action이다.
- 비활성 상태에는 누락된 인자·반응 조건을 바로 아래에 텍스트로 표시한다.
- 현재 설계 유형에는 완전요인, 일부요인, Plackett–Burman, 중앙합성,
  Box–Behnken을 표시한다. Taguchi 등 미구현 유형은 개발 예정 안내로 보낸다.
- 2026-10-28: `/doe`에 이 작업공간 셸을 구현했다. 각 설계 카드는 기존의
  검증된 설정 경로로 이동하며, 실행 데이터·분석·결과·최적화·근거 탭은 해당
  작업 단계와 가장 가까운 현재 기능으로 안내한다.

## SCR-034 SPC 작업공간

```text
┌ 통계적 공정관리(SPC) > 관리도 ─────────────────────────────────┐
│ ① 종류 선택 ───── ② 데이터 입력·검증 ───── ③ 분석 결과·출력    │
├ 관리도 카드: I-MR | Xbar-S | p/np/c/u | EWMA | CUSUM | Laney | G/T ┤
│ 선택한 관리도 설명 · 사용 조건 · 예시 · 전용 파라미터           │
├ 데이터 원본: 작업표 선택 | CSV | 직접 입력 | 표본 데이터        │
│ 완료 조건/검증 오류                                  [분석 실행] │
├ 결과: 관리 한계 칩 → 차트 → 접근 가능한 원본 표 → 이상 신호    │
│ 요약: CL/UCL/LCL/관리 한계 내 점 · 근거 · 경고 · 결과 출력      │
└────────────────────────────────────────────────────────────────┘
```

- I-MR, Xbar-S, p/np/c/u, EWMA, CUSUM, Laney P′/U′, G/T 및 경험적
  비정규 공정능력은 현재 선택 가능하다. G는 0 이상 정수인 사건 간 기회 수, T는 양수인
  사건 간 시간·거리·사용량을 입력한다.
- G/T 결과는 중앙값과 LPL/UPL 확률 한계, 차트, 접근 가능한 간격 표, 이상 신호 순서로
  표시한다. Phase I 입력 자료에서 모수를 추정하며 Phase II 과거 모수 계약은 별도 증분이다.
- 결과 출력은 SPC ResultBundle을 기준으로 한다. JSON 데이터는 현재 제공하고,
  PDF·Excel·PNG·SVG는 `개발 예정`으로 명시한다.

## SCR-032 분석 결과

```text
┌ Result title | status | input digest | engine version ─┐
│ Tabs: Summary | Charts | Tables | Diagnostics | Source  │
├ KPI cards ─────────────────────────────────────────────┤
│ Primary chart (8 cols)             │ signals (4 cols)  │
```

- 차트 결측은 선을 끊고 0으로 연결하지 않는다.

## SCR-041 FMEA 편집

```text
┌ Study / standard version / revision / approval ────────┐
│ Structure tree │ Function / Failure / Risk table       │
│                │ S | O | D | AP | owner | due | status │
│                ├───────────────────────────────────────┤
│                │ selected failure DetailDrawer         │
└────────────────────────────────────────────────────────┘
```

- 표준 버전 변경은 새 revision을 만든다.
- 위험은 색과 함께 텍스트·아이콘으로 표시한다.
- 승인 보고서는 인증 여부와 함께 `독립 승인 적용/미적용`, 이전 변경자 일치 판정을
  한 줄로 표시한다. 이 판정은 로컬 감사 actor 비교이며 기업 IdP 신원 검증을 뜻하지 않는다.

## SCR-060 개발 예정 안내

```text
┌ 기능명                                      [개발 예정] ───────┐
│ 이 기능은 아직 분석을 실행할 수 없습니다.                       │
│ 제공 예정 범위: …                                               │
│ 선행 조건: …                                                    │
│ 지금 사용할 수 있는 기능: [가까운 현재 기능으로 이동]           │
└───────────────────────────────────────────────────────────────┘
```

- 외부 AP 정책이나 기업 IdP처럼 고객 조직의 입력이 필수인 기능은
  `외부 정책 필요`를 표시하고, 지원되었다는 인상을 주지 않는다.
