# StatPro 와이어프레임 V1.0

## SCR-001 홈 대시보드

```text
┌ Header: StatPro | 환경 | 테마 | 사용자 ─────────────────────┐
├ Sidebar ┬ Main ────────────────────────────────┬ Issues ┤
│ 홈      │ KPI: 프로젝트 / 실행 / 신호 / 조치  │ 기한초과│
│ 데이터  │ 최근 프로젝트                       │ 경고    │
│ 분석    │ 최근 분석 추세                      │         │
│ FMEA    │ 데이터 품질 알림                    │         │
│ 리포트  │                                     │         │
└─────────┴─────────────────────────────────────┴─────────┘
```

- KPI 클릭: 표준 DetailDrawer를 열고 URL에 detail query를 기록한다.
- 768px 미만: 미지원 안내 화면을 표시한다.

## SCR-020 워크시트

```text
┌ Header ─────────────────────────────────────────────────┐
├ Sidebar ┬ Filter/Transform Bar ─────────────────────────┤
│         │ Column profile: type · missing · min/max      │
│         ├───────────────────────────────────────────────┤
│         │ sticky columns | virtualized data table       │
│         │ numeric cells right aligned                   │
└─────────┴───────────────────────────────────────────────┘
```

- 열 선택 시 프로파일 drawer를 연다.
- 결측은 빈 문자열이나 0과 구분되는 전용 표시를 사용한다.

## SCR-031 분석 설정

```text
┌ Method title + public source ───────────────────────────┐
│ Variables                    │ Options                  │
│ [measurement column]         │ [limits/rules/seed]      │
│ [subgroup column]            │                          │
├ Validation summary ────────────────────────────────────┤
│ Assumptions · warnings · estimated cost                 │
└────────────────────────────────────── [Run analysis] ──┘
```

- 레이블은 placeholder로 대체하지 않는다.
- blur 시 필드 검증, 제출 시 전체 검증 후 첫 오류로 포커스를 이동한다.

## SCR-032 분석 결과

```text
┌ Result title | status | input digest | engine version ─┐
│ Tabs: Summary | Charts | Tables | Diagnostics | Source  │
├ KPI cards ─────────────────────────────────────────────┤
│ Primary chart (8 cols)             │ signals (4 cols)  │
│ accessible source data table                           │
│ assumptions · warnings · provenance                    │
└────────────────────────────────────────────────────────┘
```

- 차트 결측은 선을 끊고 0으로 연결하지 않는다.
- 차트마다 접근 가능한 요약과 원본 표를 제공한다.

## SCR-041 FMEA 편집

```text
┌ Study / standard version / revision / approval ────────┐
│ Structure tree │ Function / Failure / Risk table       │
│                │ S | O | D | AP | owner | due | status │
│                ├───────────────────────────────────────┤
│                │ selected failure DetailDrawer         │
└────────────────────────────────────────────────────────┘
```

- 표준 버전 변경은 새 revision을 만든다.
- 위험은 색과 함께 텍스트·아이콘으로 표시한다.

## 반응형

- 1440px 이상: Sidebar 240, Main, Aside 320 구조
- 1024–1439px: Aside를 Main 하단으로 이동
- 768–1023px: Sidebar 64, 2열 그리드
- 768px 미만: 지원 범위 안내
