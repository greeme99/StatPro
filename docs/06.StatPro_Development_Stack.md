# StatPro 개발 스택 정의서 V1.2

> 최신 기준일: 2026-11-08. 코어·API·웹·문서의 현재 구현 경계와 명시적 목표 백로그를 분리해 반영한다.

## 1. 기술 스택

| 구분 | 기술 | 버전 | 용도 |
|---|---|---|---|
| Statistical Core | Python | 3.12 | 검증 가능한 통계 계산과 계약 |
| Packaging | setuptools/pyproject | PEP 517 | 설치 및 CLI 배포 |
| Test | unittest + HTTPX2 TestClient | Python 표준 / 2.14 | 코어 및 HTTP 계약 테스트 |
| Frontend | React + TypeScript + Tailwind + Recharts + Vite | 19.3 / 7.0 / 4.3 / 3.10 / 8.3 | 업무용 로컬 웹 UI와 관리도 |
| Chart benchmark | ECharts | 6.1.0 | 제품 런타임이 아닌 격리 성능 비교 전용 |
| Frontend Test | Vitest + Testing Library + jsdom | 5.0 / 16.3 / 30.1 | 사용자 흐름·접근성 계약 테스트 |
| API | FastAPI + Uvicorn + Pydantic | 0.148 / 0.54 / 2.13 | loopback 로컬 서비스와 OpenAPI |
| Data | Atomic JSON Document Store | V1 envelope | 단일 프로세스 로컬 Analysis Run·Worksheet·FMEA revision 저장 |
| OSS governance | 저장소 내 정책 검사 + CycloneDX | 1.5 | 직접 의존성 목적, SPDX 허용 목록, lock 일치, SBOM 최신성 fail-closed 검사 |

## 2. 현재 구조

```text
src/statpro/
  analyses/       통계 방법 구현
  domain/         오류 및 ResultBundle 계약
  version.py      패키지·통계 엔진 버전의 단일 소유자
  schemas/        배포 패키지에 포함되는 Draft 2020-12 JSON Schema
  fmea/           통계 분석과 분리된 FMEA 모델·상태 전이
  application/    저장 interface와 메모리/원자적 JSON adapter
  api/            FastAPI HTTP adapter와 loopback launcher
  cli.py          JSON CLI 어댑터
tests/            공개 예제와 경계조건 검증
samples/          재현 가능한 입력
docs/             7단계 산출물
web/              React UI, 디자인 토큰, UI 테스트와 Vite 구성
```

제품 런타임의 차트 엔진은 Recharts로 고정한다. ECharts는 대규모 SVG 렌더링 비교를 위한 `web/benchmarks/chart-engines/` 경계 밖으로 확장하지 않는다.

## 3. 설계 규칙

- 도메인 계약은 CLI/UI/API보다 안쪽에 있다.
- 분석은 전역 상태를 사용하지 않고 같은 입력에 같은 결과를 반환한다.
- 각 방법은 공개 출처, 입력 digest, 엔진 버전, 가정, 경고를 반환한다.
- 유효하지 않은 입력은 `AnalysisInputError`로 명시적으로 실패한다.
- 표시 반올림은 계산 코어 밖에서 수행한다.

## 4. 보안

- 실제 제조 데이터와 자격증명을 저장소에 커밋하지 않는다.
- `.env`는 무시하고 예제에는 비밀값을 넣지 않는다.
- 로컬 우선이며 네트워크 전송은 후속 명시적 기능으로만 추가한다.
