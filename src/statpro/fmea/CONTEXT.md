# FMEA Glossary

| Term | Meaning |
|---|---|
| FMEA Study | A versioned risk-analysis record for a product design or manufacturing process. |
| Study Revision | An immutable state of an FMEA Study linked to its parent state. |
| Structure Element | The product element or process step being analyzed. |
| Function | What a Structure Element is intended to do. |
| Requirement | The measurable or observable condition the Function must satisfy. |
| Failure Analysis | The connected Failure Mode, Effect, Cause, controls, and risk evaluation for one requirement. |
| Failure Mode | A way a Function or Requirement may fail to be satisfied. |
| Effect | The consequence of a Failure Mode at the relevant customer or system level. |
| Cause | The mechanism or condition that can produce a Failure Mode. |
| Prevention Control | A current control intended to prevent a Cause or reduce its occurrence. |
| Detection Control | A current control intended to detect a Cause or Failure Mode before release. |
| Risk Ratings | Severity, Occurrence, and Detection ordinal assessments from 1 through 10. |
| Risk Priority Number | Severity × Occurrence × Detection; it is not a substitute for standards-governed Action Priority. |
| Action Priority | A policy-versioned priority derived from Risk Ratings using a separately supplied authorized policy. |
| Recommended Action | Assigned work intended to improve prevention, detection, or the design and followed through completion. |
| Current Evaluation | The latest Risk Ratings after completed actions; it does not overwrite the Initial Evaluation. |
| Audit Event | An append-only record of who performed a workflow transition and when. |
| Approval | A workflow decision that freezes an in-review Study Revision as approved evidence. |
