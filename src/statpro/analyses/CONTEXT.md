# Statistical Analysis Glossary

| Term | Meaning |
|---|---|
| Analysis Definition | The selected method, input bindings, options, and algorithm version needed to reproduce an analysis. |
| Analysis Run | One execution of an Analysis Definition against exact input snapshots. |
| Result Bundle | Tables, plots, diagnostics, warnings, assumptions, and provenance produced by an Analysis Run. |
| Rational Subgroup | Measurements grouped because they were produced under comparable short-term conditions. |
| Control Limit | A statistically estimated process-behavior boundary; it is not a Specification Limit. |
| Specification Limit | A customer or engineering acceptance boundary; it is not calculated from process behavior. |
| Signal | A configured control-chart rule violation requiring investigation, not automatic proof of a special cause. |
| Capability Study | An assessment comparing a stable process distribution with engineering Specification Limits. |
| Within Sigma | A short-term variation estimate from variation within rational subgroups or successive observations. |
| Overall Sigma | Variation estimated across all observations in the study period. |
| Experiment | A planned set of runs that varies Factors and observes Responses. |
| Factor | A controllable or recorded explanatory variable in an Experiment. |
| Response | An observed outcome analyzed in an Experiment. |
| Standard Order | The canonical, non-randomized order used to identify factorial treatment combinations. |
| Run Order | The order in which experimental runs are intended to be performed. |
| Center Point | A run at the midpoint of every quantitative factor, used separately from factorial corner points. |
| Measurement System Analysis | Evaluation of variation introduced by the measurement process. |
| Repeatability | Variation when the same operator repeatedly measures the same part with the same gage. |
| Reproducibility | Variation attributed to operators and part-by-operator interaction in the supported crossed study. |
| Number of Distinct Categories | The number of process-value groups that the measurement system can distinguish. |
