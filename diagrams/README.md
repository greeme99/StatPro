## 2. 모션 가이드 HTML 조작 단축키

* **`Space`**: 자동 설명 재생 / 일시정지 (Play / Pause)
* **`← / →`**: 이전 단계 / 다음 단계 수동 탐색
* **`1` / `2`**: 1(전체 표준 파이프라인) / 2(DMAIC 도메인 연계) 뷰 전환
* **`R`**: 처음부터 다시 재생 (Restart)
